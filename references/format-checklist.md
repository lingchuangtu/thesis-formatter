# 论文格式逐项验收清单

交付前必须逐项核对。任何一项未通过，回到对应脚本/步骤修正后重新验证，直到全部通过。
本清单是“所有要求都必须达到”的权威依据；验收报告由 `scripts/verify_requirements.py` 生成。

## A. 版式与页面（页边距 / 页码 / 页眉页脚）

- [ ] **纸张大小**：与模板一致（A4 = 11906×16838 twips）。`inspect_template.py` 的 `pgSz` 对照。
- [ ] **页边距**：上、下、左、右、装订线、页眉距、页脚距逐项与模板 `pgMar` 一致。
- [ ] **分节与方向**：分节数量、每节纸张方向（portrait/landscape）、分栏 `cols` 与模板一致。
- [ ] **首页不同**：封面不显示页码/页眉时，`titlePg` 必须与模板一致。
- [ ] **页码域**：页脚或页眉中存在 `PAGE` 域（不是手打数字）；页脚含“第 X 页”时 X 必须是域。
- [ ] **总页数域**：若模板含 `NUMPAGES` / `SECTIONPAGES`，必须保留为域。
- [ ] **页码格式**：`pgNumType.fmt`（decimal / lowerRoman / upperRoman / lowerLetter 等）与模板一致。
- [ ] **页码起始**：`pgNumType.start` 与模板一致（如正文从 1 开始）。
- [ ] **页眉文字**：每节每个类型（default / first / even）的文字、域、对齐方式与模板一致。
- [ ] **页脚文字**：同上；学校 Logo、横线等对象必须随模板保留（通过整包克隆实现）。

## B. 字体与字号

- [ ] **正文中文** font_eastAsia 与模板“正文/Normal”样式一致（常见：宋体小四 12pt）。
- [ ] **正文西文** font_ascii / font_hAnsi 与模板一致（常见：Times New Roman）。
- [ ] **各级标题**中文字体、西文字体、字号、加粗、颜色与模板 Heading1/2/3 一致。
- [ ] **摘要/关键词**“摘要”“关键词”“Abstract”“Key words”样式与模板一致。
- [ ] **图表题注**字体字号（常见：宋体五号）与模板 Caption/题注样式一致。
- [ ] **参考文献**字体字号、悬挂缩进与模板 Bibliography/参考文献样式一致。
- [ ] **无硬编码字号**：正文段落不写死 `w:sz`，而是继承样式（模板为唯一字号来源）。

## C. 段落格式

- [ ] **对齐方式**：正文两端对齐（both）、标题居中/左对齐等与模板一致。
- [ ] **首行缩进**：正文首行缩进 2 字符（firstLineChars=200 或 firstLine≈420twips）。
- [ ] **行距**：line 与 lineRule（auto 倍数 / exact 固定值）与模板一致（常见：固定值 20 磅或 1.5 倍）。
- [ ] **段前段后**：spacing before/after 与模板一致。
- [ ] **孤行控制**：keepNext / keepLines / widowControl 与模板一致（标题不与正文分离）。
- [ ] **大纲级别**：各级标题 outlineLvl 正确（0/1/2…），保证目录可自动生成。

## D. 结构与内容

- [ ] **章节齐全**：封面、摘要、Abstract、目录、正文各章、结论、参考文献、致谢、附录（按模板/学校要求）。
- [ ] **章节顺序**：与模板/学校要求一致，无缺章、无错位。
- [ ] **目录**：目录项与正文标题级别对应，页码为域或已更新。
- [ ] **连续编号**：图、表、公式编号按章连续，如“图 3-2”。
- [ ] **参考文献**：引用编号与文末列表一一对应，格式符合学校规范（GB/T 7714 等）。
- [ ] **必备文字**：`requirements.json` 中 required_text 全部存在。
- [ ] **无残留占位**：`forbidden_text`（如“XXX”“待补充”“【填写题目】”）全部清除。

## E. 交付

- [ ] **可编辑**：输出为 .docx，可在 Word/WPS 打开并编辑，无损坏。
- [ ] **验证报告**：`verify_requirements.py` 输出 FAIL=0；如学校有硬性附加要求，用 `--requirements` 覆盖检查。
- [ ] **原模板未改动**：模板文件保持原样，所有修改发生在输出副本上。
